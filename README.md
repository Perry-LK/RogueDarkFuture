# FutureDark

Working design documentation for a solo-developed tactical deckbuilding roguelike built in Godot with C#.

## Documents

- [Game design document](docs/GAME_DESIGN.md): vision, confirmed rules, combat loop, progression, prototype content, and open questions.
- [Godot implementation outline](docs/GODOT_IMPLEMENTATION.md): technical structure, development milestones, and acceptance criteria.

## The pitch

Lead a resistance movement or a district security organisation through the same dystopian district. Navigate branching encounters, deploy troops from a deck onto irregular tactical boards, and exploit predictable enemy routines whose exact intentions require reconnaissance.

Every enemy attack threatens the organisation, even when no troop is nearby. Nearby troops can suffer the same attack as well. Spend limited cards and action points deciding what to protect, when to deploy, and when to strike.

## Current scope

Documentation and planning only; no playable implementation yet.

The first prototype targets desktop and includes the resistance leader, one short branching area, and a boss. The full design targets five main acts and a short sixth-act finale, with a second playable security leader. Mobile and permanent unlocks are later considerations.

**Decision labels:** **Confirmed** reflects agreed requirements. **Proposed** is an adjustable recommendation. **Open** requires a decision before implementing the affected behaviour.
